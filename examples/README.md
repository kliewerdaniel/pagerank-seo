# Examples

This directory contains runnable examples showing how to use `pagerank-seo`
from Python and from the command line.

## Files

| File | What it shows |
|---|---|
| `audit_python.py` | End-to-end audit using the Python SDK |
| `audit_before_after.py` | Compare two audits and print the diff |
| `output/audit-example.com.{json,markdown,html}` | Real audit outputs from running against `https://example.com` |

## Reproducing the example output

```bash
pagerank-seo audit https://example.com \
    --max-pages 5 \
    --max-depth 2 \
    --output json,markdown,html \
    --out-dir examples/output/
```

The output files in `output/` were generated by this command on 2026-09-03
against the canonical IANA-reserved `example.com`. Re-running may produce
slightly different scores if `example.com` is updated.
